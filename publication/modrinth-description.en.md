# Farmer's Delight — Fabric source builds

An unofficial source-built distribution of **Farmer's Delight Refabricated** for **Minecraft 26.2 and 26.3** on **Fabric**.

Farmer's Delight expands farming and cooking with crops, knives, cutting boards, cooking pots, meals, rich soil, rope and kitchen decorations. This distribution uses the existing Fabric port and provides the corresponding source projects and build information. It does not add new gameplay features.

## Installation

1. Install Fabric Loader for your Minecraft version and use Java 25.
2. Install Fabric API and the mod JAR for that exact game version on the client and server.
3. Do not install another Farmer's Delight implementation with the same `farmersdelight` ID in the same instance.

Recipe viewers and configuration-screen mods are optional. Source JARs are for development and must not be installed as the mod.
