# Farmer's Delight — сборки для Fabric

Неофициальные сборки существующего порта **Farmer's Delight Refabricated** для **Minecraft 26.2 и 26.3** на **Fabric**.

Мод расширяет фермерство и готовку: добавляет культуры, ножи, разделочные доски, кастрюли, блюда, плодородную почву, верёвки и кухонные украшения. Здесь используется готовый Fabric-порт; вместе со сборками предоставляются соответствующие исходники и сведения о сборке. Новых игровых механик в этой версии нет.

## Установка

1. Установи Fabric Loader для своей версии Minecraft и используй Java 25.
2. Установи Fabric API и JAR мода для этой же версии на клиент и сервер.
3. Устанавливай только один мод с идентификатором `farmersdelight` в одном игровом экземпляре.

Просмотрщики рецептов и моды с экраном настроек необязательны. Файлы `-sources.jar` предназначены для разработки.
